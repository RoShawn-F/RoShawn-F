## 🚀 Featured Projects

### [SpaceX Falcon 9 Landing Prediction](https://github.com/RoShawn-F/spacex-falcon9-landing-prediction)
*IBM Data Science Professional Certificate capstone · It's not a phase, it's a pipeline.*

An end-to-end project predicting whether a Falcon 9 first stage will land, which determines whether a launch costs about $62M or $165M+.
- Collected launch data from the **SpaceX REST API** and by **web scraping** Wikipedia with BeautifulSoup
- Cleaned the data, engineered a landing label, and explored it with **SQL** and **seaborn**
- Built **interactive Folium maps** of launch sites and a **Plotly Dash** dashboard
- Trained and tuned **Logistic Regression, SVM, Decision Tree and KNN** models with GridSearchCV: best model **88.9% validation / 83.3% test accuracy**
- 📊 [View the final presentation](https://github.com/RoShawn-F/spacex-falcon9-landing-prediction/blob/main/SpaceX%20Capstone%20-%20Crimson%20Edition.pdf)

### [Rain Prediction in the Melbourne Area](https://github.com/RoShawn-F/rain-prediction-ml)
*IBM Machine Learning with Python final project*

A classification model predicting same-day rain from the previous day's weather, built with a scikit-learn pipeline.
- Reframed the problem to **avoid data leakage** and engineered a seasonal feature
- Compared **Random Forest** and **Logistic Regression** with stratified cross-validation
- Evaluated beyond accuracy on an imbalanced target: recall, precision, and confusion matrices
- **Random Forest: 84% accuracy**, with afternoon humidity as the strongest predictor
